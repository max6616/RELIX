# Input and output formats

## Integrated simulation CSV

Leading `# key: value` lines record instrument geometry, acquisition settings,
source identity and simulation seeds. The `# Columns:` header defines the data
columns. Standard integrated columns are:

| Column | Meaning | Unit / role |
|---|---|---|
| x_px, y_px | detector centroids | pixels; model inputs |
| angle | rotation angle | degrees; model input |
| I_LP | generated intensity with the frozen simulator weighting | relative; model input |
| h, k, l | simulator reference integer indices | reference only |
| qx, qy, qz | simulator reference reciprocal coordinates | reference only |

The RELIX CSV reader selects only the first four measured quantities by column
name. Instrument metadata provide distance in mm, beam centre in pixels, pixel
size in micrometres, wavelength in angstroms and the rotation-axis unit vector.
The original simulator label sidecars record the jointly transformed primitive
cell, orientation and indices; use the sidecars for those reference conventions.

## Measurement-only NPZ

- `raw`: N by 4 array, ordered x_px, y_px, angle_deg, I_LP.
- `geometry_json`: JSON string with `distance_mm`, `center_px`, `pixel_mm`,
  `wavelength_A`, `rotation_axis`, and `apply_lp_correction`.

An NPZ for this interface contains measured data and instrument settings. The
model never consumes the simulation reference cell, orientation or HKL labels.

## RELIX output

`indexing.npz` contains the available fields among:
`q`, `basis`, `hkl`, `accepted`, `cell`, `orientation`, `space_group`,
`space_group_probability`, `diffraction_class`, and
`diffraction_class_probability`.

`q` is the final N by 3 reciprocal-coordinate array after the executed geometry
refinement. The reciprocal basis uses columns: fractional indices are
`q @ inv(basis).T`. `hkl` gives the integer assignments in that returned basis;
`accepted` is the per-reflection native acceptance mask. Cell lengths are in
angstroms and cell angles in degrees. Space-group numbers are 1 to 230.
Diffraction-class indices are 0-based and refer to the included
`RELIX/lattice_aligned/assets/symmetry_122.json` mapping. Independent class and
space-group predictions are retained.

These files are generated by the user's own indexing command. The release
contains input examples, without stored paper predictions or result tables.
